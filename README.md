# Davis Byrd — Portfolio

Personal portfolio and résumé site for Davis Byrd, AI/ML Engineer. Covers education, credentials, work experience, technical skills, and projects.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No build tools or frameworks — static site, open `index.html` directly or serve the folder with any static file server.

## Structure

```
index.html          # Main page
css/styles.css       # Styles
js/main.js           # Interactivity
assets/images/        # Images, favicon
assets/resume/        # Résumé (docx)
```
